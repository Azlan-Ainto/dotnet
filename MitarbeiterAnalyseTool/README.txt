# Mitarbeiter-Analyse-Tool

## Projektbeschreibung
Dieses Projekt ist eine Konsolenanwendung zur Verwaltung und Analyse von Personaldaten. 
Es dient als Projekt 1 zur Erlernung von C# und objektorientierter Programmierung.

## Verwendete Technologien
- Visual Studio 2026
- C# / .NET 8.0

## Lernfortschritt Tag 1
- Anforderungsanalyse durchgeführt.
- Entität "Mitarbeiter" erstellt.
- Grundlegendes Debugging in Visual Studio trainiert.
